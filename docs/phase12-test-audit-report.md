## 二、54 章超时的精确数学证据与阶段耗时分析

### 1. 为什么会在 300 秒精确超时？

在真实小说长章节转译中，单章包含完整的 7 个 Agent 阶段与多场景并行处理。通过提取数据库中每个 Stage 的实际平均耗时：

```
[单章典型耗时分布]
1. 叙事解析 (Narrative Parsing)  : ~240s (长章节多分块+API排队)
2. 角色归属 (Attribution)         : ~45s (BM25+向量检索+LLM重排)
3. 场景切分 (Scene Segmentation)  : ~55s
4. 场景剧本映射 (VN Mapping x3)  : ~40s
5. 保真度审查 (Fidelity Review x3): ~15s
------------------------------------------------------------
单章总耗时区间                    : 380s ~ 450s (约 6.3 ~ 7.5 分钟)
```
